# cnc-toolpath-gcode-simulator

[![Live demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-58d6c7)](https://raghav1822.github.io/cnc-toolpath-gcode-simulator/)

Interactive 2.5D contour milling toolpath planner for circular, slot, and rectangular profiles. It estimates toolpath length, cycle time, rapid travel, and depth passes, then exports G-code.

## Run locally

```bash
npm test
npm run serve
```

Open `http://localhost:8080`.
